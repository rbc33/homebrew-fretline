# rbc33/homebrew-fretline

Tap de Homebrew para [Fretline](https://github.com/rbc33/Fretline), lector de tablaturas con importación de Guitar Pro / Songsterr y sincronización con YouTube (macOS 14+).

## Instalar

```sh
brew install --cask rbc33/fretline/fretline
```

O añadiendo el tap primero:

```sh
brew tap rbc33/fretline
brew install --cask fretline
```

## Actualizar

```sh
brew upgrade --cask fretline
```

Las versiones nuevas se publican con `release.sh` desde el repo de [Fretline](https://github.com/rbc33/Fretline): sube el `.dmg` a GitHub Releases y actualiza la cask de este tap.
